BioDev Lab

Biomedical Device Engineering

BioDev Lab is dedicated to resolving severe clinical bottlenecks. Our current marquee initiative is the Edge AI Dengue Fluid-Shift Monitor, a non-invasive tool mapping plasma leakage using Bioelectrical Impedance Analysis (BIA/BIVA).

  • TCV Focused: Reduces patient clinic Time, Cost, and Visits (TCV) in primary care clinics.
  • Clinical Grade AFE: Engineered using the MAX30001 bio-impedance acquisition module.
  • Early-Warning System: Integrates machine learning to predict plasma shift anomalies before medical shock.

QuantaMax Lab

Quantum Computer Design

QuantaMax Lab pushes the limits of solid-state engineering, targeting the construction of reliable, fault-tolerant quantum computer processors. One PCF one QPU → envisioned in 1 PCF multiple QPU.

  • Topological Topologies: Designing circuits resilient to quantum noise and decoherence.
  • Molecular Simulations: Powering algorithms for fast chemical bonding and vaccine candidate design.
  • Error Correction Modeling: Simulating surface codes to build scalable multi-qubit systems.

Technical Architectures

Explore the granular engineering and computational designs powering both laboratories.

Dengue BIA Fluid-Shift Monitor

Using high-frequency, ultra-low current bio-impedance measurements, we calculate extracellular-to-intracellular fluid ratios. This provides non-invasive warning signals for critical plasma leakage in clinical environments.

Core AFE
ProtoCentral MAX30001
Microcontroller
Adafruit ESP32 Feather V2
BIA Sweep Range
50 kHz - 100 kHz
Power Isolation
Clinically Isolated LiPo (IEC 60601)

BIVA System Architecture

Standard ECG Electrodes (Current Injection)
MAX30001 Clinical AFE (SPI Resistance/Reactance Sweep)
ESP32 Edge AI Algorithm (Fluid Shifts / TBW Ratios)
Decision making using data or image using ML
